# Dota Activity

Windows-приложение автоматически показывает статус Dota 2 в Discord Rich Presence.

## Для игроков

1. Установи настольные Discord и Dota 2 через Steam.
2. Скачай `DotaActivity.exe` из раздела [Releases](https://github.com/Kolt5ik/DotaActivity/releases).
3. Запусти файл. Чтобы убрать окно, нажми «Свернуть в трей» или крестик. Приложение останется в системном трее и продолжит синхронизацию с Discord.

Верни окно через значок приложения в системном трее. «Выход» полностью останавливает приложение, Discord RPC и локальный GSI-сервер. Python и отдельные библиотеки устанавливать не нужно. Приложение само подключается к Discord, находит Dota 2 в папках Steam (включая дополнительные библиотеки) и устанавливает GSI-конфиг. Если Dota 2 уже открыта при первом запуске приложения, перезапусти игру один раз, чтобы она загрузила конфиг.

## Что отображается

В Discord активность называется «Dota». Во время выбора и подготовки матча показывается логотип Dota, в самой игре и после неё — портрет героя. Во время матча отображаются герой, K/D/A, режим, net worth и длительность, если Dota передаёт эти данные. Рейтинг, тренировка и игра против ботов подписываются отдельно, когда тип режима или лобби присутствует в GSI. Картинки загружаются Discord по ссылкам на изображения Dota 2.

## Разработка

Для запуска исходников нужны Windows 10/11, Python 3.10+ и интернет при первом запуске `run.bat`.

```powershell
run.bat
py -m unittest discover -s tests
build.bat
```

Сборка появится в `dist\DotaActivity.exe`.

## Ветки и сборки

Изменения вносятся в `feature/*` или `fix/*` и попадают в `main` через Pull Request. GitHub Actions собирает тестовый `.exe` для проверки в PR. Версионный релиз с `.exe` создаётся после слияния PR в `main` и публикации тега `vX.Y.Z`.

## Конфиденциальность

Приложение принимает GSI только на `127.0.0.1` и не входит в Steam-аккаунт. Проект не связан с Valve или Discord. Лицензия будет добавлена отдельно перед первым публичным релизом.
