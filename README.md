# Dota Activity

Компактное приложение для Windows, которое показывает игровую активность Dota 2 в Discord Rich Presence.

## Запуск готового приложения

Скачай `DotaActivity.exe` из [последнего релиза](../../releases/tag/latest) и открой файл. Python, pip и отдельная установка библиотек не нужны: они упакованы в `.exe`.

На компьютере уже должны быть установлены и запущены настольный Discord и Dota 2. В этой ранней версии при первом запуске укажи Discord Application ID. Его нужно создать в Discord Developer Portal; для картинок Dota и героев можно добавить Rich Presence Art Assets в настройках этого приложения Discord. Настройки приложения сохраняются в `%APPDATA%\DotaActivity`.

Чтобы автоматически получать игровые события, нажми «Установить GSI-конфиг» и выбери папку `game\dota\cfg` в установленной Dota 2. Приложение отправляет GSI только на `127.0.0.1`.

## Возможности первой версии

- ручные статусы: главное меню, поиск матча, матч найден, игра, после матча, наблюдение и приватное лобби;
- автоматические статусы выбора героя, игры и послематчевого экрана;
- герой, режим, K/D/A, net worth, длительность игры и результат матча, если Dota передала эти данные;
- локальный предпросмотр и сохранение настроек.

Поиск матча, наблюдение и приватное лобби выставляются вручную: Dota GSI не сообщает об этих состояниях одинаково надёжно во всех версиях клиента.

## Разработка и локальная сборка

Для разработки нужны Windows 10/11 и Python 3.10+. Установи зависимости и запусти приложение:

```powershell
py -m pip install -r requirements.txt
py app.py
```

Чтобы собрать самостоятельный Windows `.exe`:

```powershell
build.bat
```

Файл появится в `dist\DotaActivity.exe`. Скрипт сам установит PyInstaller и зависимости сборки.

## Автоматическая сборка

Каждый push в `main` запускает тесты и сборку Windows x64 `.exe` в GitHub Actions, а затем обновляет rolling-релиз `latest`. Pull request проверяется тестами и сборкой, но не публикует релиз.

## Проверки

```powershell
py -m unittest discover -s tests
```

## Конфиденциальность и статус проекта

Приложение не входит в Steam-аккаунт и не отправляет игровые данные на внешний сервер. GSI принимает локальный сервер приложения, а Discord RPC подключается к настольному Discord.

Это независимый проект сообщества, не связанный с Valve или Discord. Лицензия пока не выбрана; до её добавления не следует считать публичный исходный код разрешённым для повторного использования или распространения.
