# Dota Activity

Небольшое Windows-приложение, которое показывает статус Dota 2 в Discord Rich Presence.

**Автор проекта: [Kolt5ik](https://github.com/Kolt5ik).**

**Версия:** 0.0.6.

## Скачать и запустить

После публикации релиза скачай `DotaActivity-v0.0.6-Windows-x64.exe` со страницы [GitHub Releases](https://github.com/Kolt5ik/DotaActivity/releases) и открой файл. Python и отдельные библиотеки устанавливать не нужно. Нужны настольные Discord и Dota 2 из Steam.

Приложение автоматически находит Dota 2 в библиотеках Steam и устанавливает GSI-конфиг. Активность в Discord появляется только пока запущена Dota 2 и очищается после её закрытия. Включить запуск приложения вместе с Windows можно переключателем в нижней части окна. При первом запуске, если Dota 2 уже открыта, перезапусти игру один раз, чтобы она загрузила конфиг. Закрытие крестиком сворачивает приложение в трей; пункт «Выход» полностью останавливает его.

## Что отображается

- В Discord активность называется «Dota» и показывается только при запущенной игре.
- Переключатель автозапуска Windows находится внизу главного окна; при входе приложение запускается свёрнутым в трей.
- Интерфейс по умолчанию на английском; его можно переключить на русский. Выбор сохраняется между запусками.
- При запуске приложение проверяет GitHub Releases. Если вышла более новая стабильная версия, можно согласиться на скачивание или отказаться. Кнопка «Проверить обновления» запускает проверку вручную.
- Подтверждённый EXE загружается в папку «Загрузки». Чтобы применить его, закрой приложение и запусти скачанный файл. Старый запущенный EXE не заменяется автоматически.
- Во время выбора героя и подготовки к матчу показывается стандартный красный логотип Dota, выровненный по центру.
- Во время игры и после матча показываются герой, K/D/A, режим, net worth и длительность, если Dota передаёт эти данные.
- Рейтинг, Turbo, тренировка и игра против ботов различаются по данным Game State Integration.

## Проверка и публикация

Изменения идут через feature-ветку и Pull Request в `main`. GitHub Actions собирает тестовую сборку для проверки в PR. Её не нужно скачивать для обычного использования.

После проверки и слияния PR в `main` публикуется тег `v0.0.6`. Он создаёт страницу GitHub Release с одним версионным файлом `DotaActivity-v0.0.6-Windows-x64.exe`. Для скачивания пользователям нужно брать файл со страницы Releases, а не архивы тестовых сборок из Actions.
