# Security Policy

## Supported versions

Only the latest stable release receives security fixes. The current release is **v0.0.11**. Please update to the latest stable release before reporting an issue affecting an older version.

## Reporting a vulnerability

Please report suspected security vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/Kolt5ik/DotaActivity/security/advisories/new). Do not post vulnerability details in a public issue, discussion, or pull request.

Include the affected version, Windows version, steps to reproduce the issue, and its potential impact. Remove personal information and do not include GSI tokens or other credentials in a report.

If private vulnerability reporting is unavailable, open a GitHub issue asking for a private reporting channel. Do not include technical details that could expose users before a fix is available.

## Response

Reports will be reviewed and handled through the private channel where possible. Response and fix timelines depend on the report; no fixed response time is guaranteed.
