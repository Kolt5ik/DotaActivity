Dota Activity — UI Beta

Это отдельная локальная бета интерфейса, основанная на версии 0.0.11. Она не загружена на GitHub и не меняет опубликованный релиз.

В этой сборке:
- Фиолетовые акценты и метка UI BETA в окне, чтобы отличать её от обычной версии.
- Числа и разделители в статусе Discord одинаковы для русского и английского языков.
- Таймер матча рассчитывается по игровому времени, полученному от Dota через GSI.
- После матча показывается только «Победа» или «Поражение», без K/D/A и других чисел.

Как запустить:
1. Распакуйте ZIP целиком в отдельную папку.
2. Закройте обычную Dota Activity через Exit в меню значка рядом с часами. Крестик только сворачивает её.
3. Запустите START-UI-BETA.bat.

При первом запуске скрипт создаст виртуальное окружение и установит зависимости. Нужны Python с командой py и интернет.
